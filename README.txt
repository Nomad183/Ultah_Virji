BIRTHDAY WEBSITE

Folder guide
  index.html   the website (open this file in a browser)
  config.js    EDIT THIS: title, message, falling wishes, picture list
  photos/      put your pictures here
  images/      the tree pictures (no need to touch)

How to update
  1. Change the words in config.js (use any text editor, e.g. Notepad).
  2. Copy your pictures into the photos folder.
  3. List the picture file names in config.js under photos.
  4. Double-click index.html to check it.

To put it online, upload the whole folder to a static host
(e.g. Netlify Drop, GitHub Pages). Keep the folder structure as is.
